# FixIT Care

เว็บแอปบริหารจัดการธุรกิจซ่อมโทรศัพท์และคอมพิวเตอร์ โทนสีฟ้า–ขาว พัฒนาด้วย React, Vinext และ Cloudflare D1

## ฟีเจอร์หลัก

- หน้าลูกค้าสำหรับแจ้งซ่อมและตรวจสอบสถานะ
- หน้าชำระเงินพร้อมรายละเอียดงานและช่องทางชำระ
- ปุ่มแชต LINE แบบลอยตัว
- แดชบอร์ดสำหรับผู้ดูแลระบบ
- ระบบล็อกอินแอดมินด้วยอีเมลและรหัสผ่าน
- แฮชรหัสผ่านด้วย PBKDF2 และเก็บเซสชันใน D1
- คุกกี้เซสชันแบบ `HttpOnly`, `Secure` และ `SameSite=Strict`
- ล็อกบัญชีชั่วคราวเมื่อกรอกรหัสผ่านผิดซ้ำ
- รองรับหน้าจอคอมพิวเตอร์ แท็บเล็ต และมือถือ

## โครงสร้างสำคัญ

- `app/` — หน้าเว็บและ API routes
- `app/admin/` — หน้าล็อกอิน ตั้งค่าครั้งแรก และแดชบอร์ด
- `app/admin-auth.ts` — การตรวจรหัสผ่านและจัดการเซสชัน
- `db/schema.ts` — โครงสร้างตาราง D1
- `drizzle/` — SQL migrations
- `tests/` — ชุดทดสอบ build และระบบยืนยันตัวตน

## เริ่มต้นพัฒนา

ต้องใช้ Node.js `>=22.13.0`

```bash
npm install
npm run dev
```

ตรวจสอบโปรเจกต์:

```bash
npm run build
node --test tests/rendered-html.test.mjs
npm run lint
```

## ค่าตั้งต้นระบบแอดมิน

ดูตัวอย่างตัวแปรใน `.env.example`:

- `ADMIN_EMAIL` — อีเมลแอดมินคนแรก
- `ADMIN_SETUP_TOKEN_HASH` — SHA-256 ของโทเคนตั้งค่ารหัสผ่านครั้งแรก

ห้าม commit รหัสผ่าน โทเคนจริง หรือค่าลับลงใน repository
